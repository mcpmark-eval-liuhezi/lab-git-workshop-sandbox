# Exercise 1: Git Basics

This file introduces the fundamentals of Git that every workshop participant should know before we start.

## What we cover

- How to clone a repository and navigate the file tree
- Making your first commit with a clear message
- Viewing the commit history with `git log`

## Quick tips

Always write descriptive commit messages, and keep each commit focused on one logical change. This makes `git blame` and `git rebase` much easier to reason about later.
