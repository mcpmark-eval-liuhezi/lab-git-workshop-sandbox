# Exercise 2: Branching

This exercise walks through creating, switching to, and merging branches — the core of collaborative Git work.

## What we cover

- Creating a new branch with `git branch` and checking it out with `git checkout`
- Switching between branches and comparing them with `git diff`
- Merging a feature branch back into the main branch

## Quick tips

Never work directly on `main` for long-lived features. Short-lived branches keep history clean and make code reviews easier. Use descriptive branch names like `feature/login-page` or `student-exercises`.
